# Zero Trust security

**Company:** Cloudflare  
**Sample type:** Original summary of public Cloudflare learning material; not an internal Cloudflare policy.  
**Source:** [Cloudflare Learning Center: What is Zero Trust?](https://www.cloudflare.com/learning/zero-trust/what-is-zero-trust/)

## Core idea

Zero Trust is an approach where access is not granted solely because a person or device is inside a corporate network. Each access request should be authenticated and authorized, and trust should be continually assessed.

## Common principles

- Verify identity and device context for access requests.
- Grant only the access needed for a task.
- Assume an attacker may already have reached part of the environment and limit the potential spread.
- Monitor access and re-evaluate it as conditions change.

## Practical takeaway

Network location alone is not proof that a request should be trusted. Design access controls around identity, authorization, and ongoing verification.
